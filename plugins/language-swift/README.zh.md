# @penguinharness/language-swift

为 [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness) 提供Swift语法高亮。

| 代码块标注 | 文件扩展名 |
| ---------- | ---------- |
| `swift` | `.swift` |

从 PenguinHarness 服务端的**插件**页安装，或在项目的 `.project_config.toml` 里列出：

```toml
[plugins]
"@penguinharness/language-swift" = "*"
```

语法来自 `@shikijs/langs/swift`；上游的署名与许可随该包携带。工作原理见[仓库 README](https://github.com/Myriad-Dreamin/penguin-languages)。
