# @penguinharness/language-csharp

为 [PenguinHarness](https://github.com/Prism-Shadow/penguin-harness) 提供C#语法高亮。

| 代码块标注 | 文件扩展名 |
| ---------- | ---------- |
| `csharp、c#、cs` | `.cs`、`.csx` |

从 PenguinHarness 服务端的**插件**页安装，或在项目的 `.project_config.toml` 里列出：

```toml
[plugins]
"@penguinharness/language-csharp" = "*"
```

语法来自 `@shikijs/langs/csharp`；上游的署名与许可随该包携带。工作原理见[仓库 README](https://github.com/Myriad-Dreamin/penguin-languages)。
